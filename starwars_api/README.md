# Star Wars API

This project fetches data from the Star Wars API using Node.js and the `request` module while preserving asynchronous response ordering.

## Requirements
* First line of all files: `#!/usr/bin/node`
* All files must end with a new line
* Code must follow `semistandard` style guidelines without `var`
* All script files must be executable

## Tasks

| Task | File | Description |
|---|---|---|
| 0. Star Wars Characters | `0-starwars_characters.js` | Prints all character names of a Star Wars movie by Movie ID in order |
