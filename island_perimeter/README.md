# Island Perimeter

This project implements `island_perimeter(grid)` to compute the perimeter of an island in a rectangular grid of land (`1`) and water (`0`) cells without importing external modules.

## Requirements
* First line of all files: `#!/usr/bin/python3`
* All files must end with a new line
* Code must follow PEP 8 style guidelines (version 1.7)
* No imported modules allowed
* All modules and functions must be documented
* All script files must be executable

## Tasks

| Task | File | Description |
|---|---|---|
| 0. Island Perimeter | `0-island_perimeter.py` | Calculates and returns the perimeter of the island described in `grid` |
